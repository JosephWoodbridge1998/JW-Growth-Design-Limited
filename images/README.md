# Images

This folder is for site images used across JW Growth & Design.

## Social preview image

Add your social preview image here:

- Filename: jw-growth-design-social-preview.jpg
- Recommended size: 1200×630 pixels
- This image is used when your homepage link is shared on WhatsApp, LinkedIn, Facebook, etc.
